        3. Python operators: arithmetic, comparison, logical, bitwise.  

            1. Arithmetic Operators

                Used for basic math

                a = 10
                b = 3

                print(a + b)   # 13
                print(a - b)   # 7
                print(a * b)   # 30
                print(a / b)   # 3.33
                print(a % b)   # 1 (remainder)
                print(a ** b)  # 1000 (power)

            2. Comparison Operators 

                Used to compare values (returns True/False)

                a = 10
                b = 5

                print(a == b)  # False
                print(a != b)  # True
                print(a > b)   # True
                print(a < b)   # False

            3. Logical Operators 

                Used to combine conditions

                a = 10

                print(a > 5 and a < 15)  # True
                print(a > 5 or a < 5)    # True
                print(not(a > 5))        # False

            4. Bitwise Operators 

                Work on binary (bits)

                a = 5   # 0101
                b = 3   # 0011

                print(a & b)  # 1 (AND)
                print(a | b)  # 7 (OR)
                print(a ^ b)  # 6 (XOR)

        3. Introduction to closures and decorators.  
            
            closures
                ~> A closure is a function that is defined inside another function
                ~> Remembers variables from the outer function even after it finishes

                E.g :-

                def outer(msg):
                        def inner():
                            print(msg)   # uses outer variable
                        return inner

                    func = outer("Hello")
                    func()

            Decorators :-
                ~> wrap main function to using another function.
                ~> Adds extra functionality without changing original code
                ~> use @decorators on main function.

                E.g :-

                    def my_decorator(func):
                        def wrapper():
                            print("Before function")
                            func()
                            print("After function")
                        return wrapper

                    @my_decorator
                    def say_hello():
                        print("Hello")

                    say_hello()
